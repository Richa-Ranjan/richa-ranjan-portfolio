# 💻 Run Locally

### 1. Clone

```bash
git clone https://github.com/Richa-Ranjan/richa-ranjan-portfolio.git
```

### 2. Enter the project

```bash
cd richa-ranjan-portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start development server

```bash
npm run dev
```

### 5. Production build

```bash
npm run build
```

### 6. Preview production build

```bash
npm run preview
```

---

# 🔐 Environment Configuration

Create a local `.env` file when environment variables are required:

```env
VITE_SITE_URL=http://localhost:5173
VITE_ANALYTICS_ID=
```

`.env` files are excluded from Git through `.gitignore`.

> **Security:** Never place private API keys, passwords, database credentials, tokens, or other confidential secrets inside frontend `VITE_*` variables. Vite exposes these variables to the browser.
