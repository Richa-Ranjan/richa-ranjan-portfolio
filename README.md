## Running Locally

### 1. Clone the repository

```bash
git clone https://github.com/Richa-Ranjan/richa-ranjan-portfolio.git
```

### 2. Enter the project directory

```bash
cd richa-ranjan-portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available on the local development URL shown in the terminal.

---

## Production Build

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

---

## Environment Variables

The project uses Vite environment variables when required.

Create a local `.env` file:

```env
VITE_SITE_URL=http://localhost:5173
VITE_ANALYTICS_ID=
```

> Never commit private credentials, API secrets, database passwords, access tokens, or other sensitive values to the repository.

The `.env` file is intentionally excluded through `.gitignore`.

## Deployment

The portfolio is designed for deployment using **Vercel**.

Typical deployment configuration:

```text
Framework: Vite
Build Command: npm run build
Output Directory: dist
```

After connecting the GitHub repository to Vercel, new commits to the configured branch can automatically trigger a new deployment.

## Design & Engineering Principles

The portfolio follows a few principles:

**Performance**
Keep the application lightweight and avoid unnecessary dependencies.

**Accessibility**
Use semantic HTML, accessible interactions, keyboard-friendly controls, and meaningful labels.

**Responsive Design**
The interface is designed to work across desktop, tablet, and mobile screen sizes.

**Maintainability**
Reusable React components are preferred over large monolithic components.

**Progressive Enhancement**
Interactive elements should enhance the experience without making the core content inaccessible.

**Developer Experience**
The project uses a straightforward Vite + React setup that is easy to develop, build, and deploy.
